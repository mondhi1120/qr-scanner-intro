# QR Scanner 公式紹介サイト 実装状況

確認日：2026-11-24

## 実装結果

日本語の静的紹介サイトをHTML・CSSで実装しました。緑色と白を基調に、PCでは左右に紹介文とアプリ画面を配置し、スマートフォンでは縦に表示します。実行時のJavaScript、React、npm、ビルド環境は不要です。

| 項目 | 実装内容 |
| --- | --- |
| アプリ紹介・起動 | 無料・登録不要の説明、ヘッダー・導入・末尾からアプリ本体へのリンク |
| 読み取り | カメラ、保存画像、前面・背面切替、対応端末でのライト |
| モード | 確認型・自動型・連続型、初期設定、自動型の注意、連続型の重複防止の範囲 |
| 記録・設定 | 履歴保存・個別/全件削除、お気に入り、CSV、効果音、ダーク・ライト |
| PWA | 初回準備後のオフライン利用、ホーム画面への追加 |
| 使い方 | カメラ、画像、iPhoneのSafariからアプリ本体をホーム画面に追加する手順 |
| プライバシー | カメラ映像・画像・読み取り内容の端末内処理、登録・外部解析API不要、保存の注意 |
| FAQ | 料金、対応端末、インストール、オフライン、カメラ権限、データ保存の6項目 |
| 開発背景 | 学習を目的に制作した説明、React・TypeScript・Vite・PWA・Codex・GitHub・Vercel |
| アクセシビリティ | 日本語lang、見出し階層、ランドマーク、画像の代替文、本文へのスキップ、フォーカス表示、動きを減らす設定への対応 |

FAQはHTML標準の`details` / `summary`です。カメラやデータ保存の処理を紹介サイトには追加していません。PWA・オフライン機能の説明はアプリ本体を対象にしています。

## 仕様の照合

- [公開中のアプリ本体](https://qr-scanner-green-pi.vercel.app/)をHTTPで取得し、200応答と公開されている紹介文・UIを確認しました。
- 隣接するアプリ本体リポジトリのREADME、スキャン画面、設定画面、保存処理、PWA設定を読み取り、掲載内容と照合しました。隣接リポジトリは変更していません。
- アプリ画面は、公開ページと同じJS・CSSファイル名を持つアプリ本体の本番ビルドをローカルで配信して取得しました。カメラ起動前、ライトモード、履歴なしの状態です。
- 前面・背面切替、ライト、効果音、ホーム画面への追加は環境依存と説明しています。特定OSバージョンへの対応、全端末での成功、読み取り精度などの未確認の保証は掲載していません。
- オフラインは初回オンラインでの準備後に利用でき、外部サイトの閲覧には通信が必要と説明しています。
- 履歴は端末のブラウザ内に保存され、同期はなく、データ消去等で失われる可能性とCSV保存を説明しています。

## 起動と公開後に残る確認

[index.html](../index.html)をブラウザで開くと確認できます。ビルド・インストールは不要です。HTTP配信を使う場合やGitHub Pages設定は[README](../README.md)を参照してください。

- GitHubへのPush、コミット、Pages設定変更、デプロイは行っていません。公開先での最終配信確認は公開後に必要です。
- クローラーが読むrobots.txtはホスト直下です。本リポジトリのサブディレクトリ内のrobots.txtだけでは、ホスト全体のクロール規則を設定できません。必要に応じてユーザーサイト側のルートrobots.txtにSitemap行を追加するか、Search Consoleへサイトマップを直接送信してください。
- 実機のiPhone・Androidでの表示、カメラ切替・ライト・OSのインストールメニューは今回検証していません。Windows版WebKitでの確認は、iOS Safari実機での動作保証ではありません。
- Search Consoleの所有権確認・登録リクエストは実施していません。インデックス登録・検索順位・共有サービスのOGP更新は保証できません。
